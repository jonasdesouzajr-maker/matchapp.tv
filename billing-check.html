💳 Stripe & Billing Diagnostic

Verifies everything between a customer paying and their account actually unlocking. noindex, not linked anywhere, not in the sitemap.

Verdict

The one test only you can run

This page checks everything reachable from the browser. The webhook itself is a server-to-server call from Stripe to Supabase — no browser can observe it. To confirm that final link, do this (takes ~1 minute):

  • Stripe Dashboard → Developers → Webhooks → click your endpoint
  • Click Send test webhook → choose checkout.session.completed → Send
  • Stripe should show a 200 response. Anything else (400/401/500) means it isn't wired up right.
  • Then in Supabase → SQL Editor, run:
    select * from public.stripe_events order by processed_at desc limit 5;
    A row should appear. If it does, the whole chain works.

Getting 401? JWT verification is still on — Supabase → Edge Functions → stripe-webhook → turn OFF "Verify JWT". Stripe can't send a Supabase token.
Getting 400 "Invalid signature"? The STRIPE_WEBHOOK_SECRET in Supabase doesn't match the signing secret shown on that Stripe endpoint page. Copy it again.
